# Практична робота 8 — Функції вищого порядку

## Реалізовані функції

### 1. `myMap(array, callback)`
Створює новий масив, застосовуючи callback до кожного елемента.

### 2. `myFilter(array, callback)`
Повертає новий масив лише з елементами, які пройшли перевірку callback.

### 3. `myReduce(array, callback, initialValue)`
Згортає масив до одного значення через акумулятор.

### 4. `pipe(...fns)`
Композиція функцій зліва направо.

### 5. `compose(...fns)`
Композиція функцій справа наліво.

### 6. `curry(fn)`
Перетворює функцію на каррировану форму.

### 7. `partial(fn, ...args)`
Повертає функцію з частково заданими аргументами.

### 8. `memoize(fn)`
Кешує результати викликів функції за набором аргументів.

### 9. `chain(array)`
Підтримує chainable API для послідовних трансформацій.

## Принципи
- Усі функції є чистими.
- Використано `map`, `filter`, `reduce` у власних реалізаціях.
- Є композиція, каррінг і часткове застосування.
- Є приклади для чисел, рядків і об'єктів.
