# Практична робота 10.1 — Promises та ланцюжки промісів

## Функції
- `checkAvailability(orderId)` — перевірка наявності товарів.
- `reserveItems(orderId)` — резервування товарів.
- `processPayment(orderId, amount)` — обробка оплати.
- `scheduleDelivery(orderId)` — планування доставки.
- `processOrder(order)` — повний ланцюжок обробки замовлення.

## Особливості
- Кожна функція повертає `Promise`.
- Є випадковий шанс помилки 20% на кожному етапі.
- Використано `.then()`, `.catch()` та `.finally()`.
- Є валідація вхідних даних.
- Є браузерні тести.

## Як запустити
1. Відкрити `index.html` у браузері.
2. Натиснути кнопку запуску.
3. Для тестів відкрити `tests.html`.
